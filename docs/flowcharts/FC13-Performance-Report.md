# Flowchart 13: Performance Report

## Tujuan
Membuat laporan kinerja produksi untuk evaluasi manajemen.

## Input
- Data produksi dari Flowchart 4

## Output
- Performance Report selesai

## Aktor
- Manager
- System

## Flow

```
○ START (Setelah shift selesai)

↓

□ Generate Performance Report (System)

↓

□ Review Performance (Manager)

↓

□ Dashboard Manager (Manager)

↓

○ END
```

## Hubungan dengan Flowchart Lain
- **Input** berasal dari Flowchart 4 (Submit Shift)
- **Output** adalah laporan kinerja untuk manajemen

## Catatan
- Performance Report mencakup GSPH, OEE, Achievement, dan metrik lainnya
- Digunakan untuk evaluasi kinerja produksi
- Performance Report membantu manajemen mengidentifikasi area perbaikan
