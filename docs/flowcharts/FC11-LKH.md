# Flowchart 11: LKH

## Tujuan
Membuat Laporan Kerja Harian (LKH) untuk shift yang sudah selesai.

## Input
- Data produksi dari Flowchart 4

## Output
- LKH selesai

## Aktor
- Supervisor
- System

## Flow

```
○ START (Setelah shift selesai)

↓

□ Generate LKH (System)

↓

□ Review LKH (Supervisor)

↓

□ Cetak LKH (Supervisor)

↓

○ END
```

## Hubungan dengan Flowchart Lain
- **Input** berasal dari Flowchart 4 (Submit Shift)
- **Output** adalah dokumen resmi untuk manajemen

## Catatan
- LKH dibuat setelah shift selesai
- LKH mencakup ringkasan produksi, downtime, dan pencapaian
- LKH adalah dokumen resmi yang digunakan untuk pelaporan ke manajemen
