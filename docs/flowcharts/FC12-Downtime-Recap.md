# Flowchart 12: Downtime Recap

## Tujuan
Membuat rekapitulasi downtime untuk analisis dan perbaikan.

## Input
- Data downtime dari Flowchart 6

## Output
- Downtime Recap selesai

## Aktor
- Supervisor
- System

## Flow

```
○ START (Setelah shift selesai)

↓

□ Rekap Downtime (System)

↓

□ Review Downtime (Supervisor)

↓

□ Cetak Downtime Recap (Supervisor)

↓

○ END
```

## Hubungan dengan Flowchart Lain
- **Input** berasal dari Flowchart 6 (Downtime & Hambatan Jalur)
- **Output** adalah dokumen untuk analisis downtime

## Catatan
- Downtime Recap mencakup kategori downtime: machine, dies, material, logistic
- Digunakan untuk identifikasi penyebab downtime terbesar
- Downtime Recap membantu manajemen mengidentifikasi area perbaikan
